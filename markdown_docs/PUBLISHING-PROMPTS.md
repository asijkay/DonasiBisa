# Publishing and Marketing Prompt Pack

Dokumen ini menjadi brief untuk Grok, AnythingLLM, atau AI content agent lain setelah nama brand, logo, warna, dan tujuan organisasi disepakati. Jangan mengarang testimoni, angka donasi, penerima manfaat, izin, legalitas, atau klaim dampak.

## 1. Master Brand Brief

```text
Act as a senior brand strategist and Indonesian non-profit communications lead.

Create a trustworthy, empathetic, and clear brand identity for an Indonesian online donation platform.

Known constraints:
- The platform is a single-organization donation platform.
- It supports one-time donations.
- Campaign donation modes: donor-entered amount and predefined amount options.
- Donors can donate as guests; Google login is optional for donor history.
- Payment is processed by Midtrans and/or Xendit.
- The brand name, logo, tagline, colors, organization identity, and campaign verticals are not finalized.

First, list the missing factual inputs you need. Do not invent the organization name, registration, beneficiaries, field activities, impact statistics, or endorsements.
Then propose 3 distinct brand directions. For each include:
- Brand name options (clearly mark as proposals)
- Positioning and brand promise
- Tagline options in Indonesian
- Voice and tone
- Color palette with HEX codes and accessibility notes
- Typography direction
- Logo concept brief for a designer/image model
- Trust signals that can be used only when evidence exists

Prefer sincere, transparent language over guilt, pressure, or exaggerated urgency.
```

## 2. Landing Page Copywriting Brief

```text
Act as a conversion-focused UX writer and senior Next.js landing-page designer.

Use the approved PRD.md and brand brief. Produce a complete landing page brief and all Indonesian copy for:
1. Navigation and hero
2. Primary/secondary CTA
3. Featured campaigns
4. Active campaigns listing
5. How donations work
6. Transparency / fund-use explanation (leave factual placeholders where data is missing)
7. Latest news and campaign updates
8. FAQ
9. Footer, contact, terms, privacy links

For every section provide: purpose, heading, body copy, CTA label, supporting microcopy, responsive layout notes, and accessibility notes.
Do not invent impact statistics, organization credentials, campaign outcomes, or testimonials. Use explicit `[DATA DIPERLUKAN]` placeholders.
Deliver clean Markdown first, followed by a component-level layout description suitable for Next.js + Tailwind + shadcn/ui.
```

## 3. Instagram Profile and 5 Feed Concepts

```text
Act as a social media strategist for an Indonesian donation organization.

Using the approved brand brief and only verified campaign facts, create:
- 3 Instagram bio options within current platform character limits (verify current limit before publishing)
- Profile display-name suggestions
- Profile photo/logo direction
- 5 feed post concepts
- At least 2 carousel concepts with slide-by-slide copy
- Captions, CTA, accessible alt text, and relevant hashtags for each post
- Suggested visual direction and image-generation brief

Do not use fabricated beneficiary stories or imply a donation has already been delivered unless confirmed by source material. Add a fact-check checklist for every post.
```

## 4. One Instagram Reels Script + ElevenLabs Voiceover

```text
Act as an Indonesian short-form video creative director and voiceover scriptwriter.

Create one 30–45 second Instagram Reel based on an approved, verifiable campaign brief.
Deliver:
- Hook in the first 2 seconds
- Scene-by-scene storyboard with duration
- On-screen text
- Visual/B-roll direction
- Indonesian voiceover script with natural spoken phrasing
- ElevenLabs voice direction (language, emotional intensity, pace, pauses, pronunciation notes)
- Caption, CTA, hashtags, and alt/caption accessibility notes
- Fact-check checklist

Never fabricate beneficiary identities, quotes, urgency, fundraising totals, or impact. Use placeholders where the campaign owner has not supplied evidence.
```

## 5. Content Approval Checklist

- [ ] Brand name/logo/colors approved by owner.
- [ ] Campaign facts verified by campaign admin.
- [ ] Beneficiary images/stories have documented consent.
- [ ] Donation target and progress numbers match application data.
- [ ] No false urgency, fabricated testimonials, or unverified impact claims.
- [ ] CTA points to the correct live campaign URL.
- [ ] Captions, spelling, accessibility, and links reviewed.
- [ ] Final asset and copy approved before publishing.
